# US-026 — Memory tests: digit span, pattern and sequence recall

**As a** candidate **I want** memory drills **so that** I can extend my short-term memory span.

## Acceptance criteria
- [ ] Digit span forward/backward: sequence shown one digit at a time (configurable ms), then keypad recall
- [ ] Visual pattern recall: grid with highlighted cells shown N seconds, reproduce by tapping
- [ ] Sequence recall: series of symbols/colours/positions, recall order
- [ ] Adaptive span within a session (length +1 on success, −1 on failure)
- [ ] Score = max span reached + accuracy
