# Architecture Decision Records

One file per significant, hard-to-reverse decision. Copy `0000-template.md` for a new one,
number it sequentially, and keep it to Context / Decision / Consequences / Alternatives. A
decision that's later reversed gets a new ADR that supersedes the old one (update the old
one's `status:` to `Superseded by ADR-000x`); ADRs are never edited to pretend the original
reasoning didn't happen.
